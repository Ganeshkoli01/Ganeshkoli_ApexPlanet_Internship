## Task 1: Data Immersion and Wrangling

### Project Overview
This project focuses on inspecting, cleaning, validating, transforming, and analyzing a sales dataset as part of the ApexPlanet Data Analytics Internship.

### Tools Used
- Python
- Pandas and NumPy
- Matplotlib
- Jupyter Notebook
- Excel/CSV files

### Work Completed
- Dataset loading and exploratory inspection
- Missing-value and duplicate checks
- Text standardization and data-type conversion
- Date-based feature engineering
- Sales calculation validation
- Product, category, city, gender, and monthly sales analysis
- KPI summaries and business visualizations
- Outlier detection and data-quality reporting
- Export of the final dataset and analysis reports

### Main Outputs
- `data/processed/day5_cleaned_dataset.csv`
- `data/processed/day6_feature_engineered_dataset.csv`
- `data/processed/day10_final_dataset.csv`
- Day 7 analysis reports in `reports/`
- Day 9 data-quality audit reports in `reports/`
- Day 10 final KPI, quality, monthly, category, and project-summary reports in `reports/`

### Data Quality Notes
Repeated order IDs, unknown city values, and statistical outliers are documented for review. They are not automatically removed or corrected without sufficient evidence.

### How to Run
1. Install the packages listed in `requirements.txt`.
2. Open `notebooks/Data_Immersion_Wrangling.ipynb` in Jupyter Notebook.
3. Run the cells in order.
4. Check the generated files in `data/processed/` and `reports/`.
